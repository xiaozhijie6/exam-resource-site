## 六、对「Everyone is great」的参考价值

### 可借鉴的功能

| 功能 | 来源 | 建议 |
|------|------|------|
| **AI 自动生成备考计划** | Planori / IntelliPlan | 根据考试日期 + 目标分数，一键拆分每日任务 |
| **线上自习室** | 上岸自习室 / 时光学苑 | 四六级/考研/考公分区，组队学习 + 专注计时 |
| **游戏化激励** | 我要做计划 / Forest | 打卡攒积分、解锁徽章、种树机制 |
| **暴力锁机 / 专注模式** | TITA专注 | 备考模式下屏蔽娱乐 App |
| **间隔重复复习提醒** | iienstitu | 根据艾宾浩斯曲线自动提醒复习 |
| **OKR 目标拆解** | 飞鱼计划助手 | 大目标 → 小任务 → 每日清单 |
| **番茄钟 + 统计** | 橙子计划 / Study Tracker | 记录专注时长 + 可视化报表 |

### 差异化切入点

目前市面缺少 **"备考资源 + 学习计划 + 线上自习室"三合一** 的产品。Everyone is great 已经实现了：
- ✅ 真题资源（PDF）免费+会员体系
- ✅ 刷题 + 备考指南

尚未实现（可差异化）：
- ❌ 个性化学习计划（AI 生成 + 日历同步）
- ❌ 线上自习室 / 专注模式
- ❌ 学习进度追踪 + 数据看板
- ❌ 番茄钟 + 学习统计

**建议优先级**：学习计划生成 > 番茄钟专注 > 线上自习室 > 数据看板
